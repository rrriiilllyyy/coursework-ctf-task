# CTF-задание: Web-безопасность (SQL-инъекция + SSRF)

Учебный проект, разработанный в рамках курсовой работы. Представляет собой уязвимое веб-приложение, демонстрирующее эксплуатацию двух распространённых веб-уязвимостей: SQL-инъекции и Server-Side Request Forgery (SSRF).

## 🎯 О проекте

Проект включает в себя:
- Уязвимое веб-приложение на PHP (форма входа, админ-панель).
- Базу данных MySQL с учётными записями пользователей.
- Docker-конфигурацию для быстрого развёртывания.
- Скрипт на Python для автоматизации Blind SQL-инъекции.

## 🛠️ Стек технологий
- **Backend:** PHP 8.1
- **Database:** MySQL 8.0
- **Web Server:** Nginx
- **Контейнеризация:** Docker, Docker Compose
- **Язык для эксплойта:** Python 3
- **Уязвимости:** SQL Injection (Blind), SSRF (через протокол `file://`)

## 🚀 Быстрый старт

Для развёртывания уязвимой среды выполните в корневой папке проекта:
```bash
docker compose up -d
```
После этого приложение будет доступно по адресу: http://localhost:8080.
